Roadmap

Launch and hardening

  • Keep launch readiness green and monitor scheduler freshness.
  • Regression-test public routes, malformed parameters, mobile, keyboard and reduced motion.
  • Verify origin/public HTTPS, cache markers, certificate coverage and rollback.

Next product cycle

  • Persist source-backed project entities and build bounded project pages.
  • Enable DBC collection after review, then add pool detail pages with snapshot history.
  • Add API coverage/status dashboard and MCP parity for project records.

Following cycle

  • Local watchlist without login or wallet connection.
  • User-local alerts for launches, graduation, payouts and creator recurrence.
  • Source-approved news ingestion and auditable curated creator registry.

Later backlog

  • Pyth-backed return decomposition when feeds are configured.
  • Historical compression, bounded RPC enrichment and restore drills.
  • Project graphs, relationship views, MCP pagination and structured citations.

Architecture

  • Python stdlib REST API
  • SQLite persisted snapshots
  • Scheduled ingestion with bounded collectors
  • Meteora DBC collector and pool evidence (implemented; not enabled on this deployment)
  • Vanilla responsive frontend
  • Read-only MCP client/server bridge
  • Docker services: sdb and sdb-scheduler

Not planned without evidence

  • Invented project identities
  • Uncited news or social claims
  • Buy/sell scores or financial advice
  • Wallet, seed phrase or private-key flows
  • Broad unbounded RPC scans
  • Inferred DBC relations

Yield wording

Token cards show Paid out, the cumulative payout total reported to the index in units of the asset the token pays in, and an Est. 24h fee rate = 24h volume × stacked fee ÷ market cap. Estimate, not a promise.

Definition of done

Shipped means deployed and verified.
